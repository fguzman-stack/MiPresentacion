Este sitio web

El portafolio se aloja en Vercel. El proveedor de alojamiento puede procesar registros técnicos necesarios para entregar y proteger el sitio. No añadimos publicidad ni vendemos datos personales.

Compras y licencias

Cuando una compra se procesa mediante Paddle u otra tienda, esa plataforma trata los datos necesarios para el pago, impuestos, prevención de fraude, recibos y soporte conforme a su propia política. No almacenamos datos completos de tarjetas.

Para emitir o validar una licencia podemos procesar el correo de compra, identificador de transacción o licencia, canal de venta, fechas y estado de activación. Las recetas, inventario y datos de uso local de Restaurant Costing permanecen en el equipo del cliente y no se envían al servicio de licencias como parte de una activación normal.

Conservación y solicitudes

Conservamos la información necesaria para entregar el producto, gestionar soporte, reembolsos, seguridad y obligaciones legales. Puedes solicitar acceso, corrección o eliminación escribiendo desde el correo asociado a la compra; explicaremos si eliminar un registro impide recuperar o validar una licencia.

Seguridad

No envíes contraseñas, claves privadas, códigos de compra ni bases de datos del restaurante por correo. Las copias locales y exportaciones pueden contener información sensible y deben protegerse en el equipo del cliente.
